# Como apresentar o projeto no GitHub

**Nome do repositório:** `data-modeling`

**Descrição curta (About):**

> Quadro visual para desenhar e documentar modelos de dados — tabelas, PK/FK, relacionamentos e camadas medalhão — com exportação para SQL DDL Databricks, PySpark, Mermaid e JSON. Instala com um comando no Claude e no Codex.

**Tópicos:** `data-modeling`, `data-engineering`, `er-diagram`, `databricks`, `pyspark`, `mermaid`, `medallion-architecture`, `claude-code`, `codex`, `agent-skills`.

Antes de publicar uma atualização:

- confira se os exemplos e as capturas de tela usam somente dados fictícios;
- rode `python tests/validate_repo.py` com `DATA_MODELING_PROIBIDOS` preenchido (veja [DESENVOLVIMENTO.md](DESENVOLVIMENTO.md));
- não inclua credenciais, tokens ou informações internas;
- atualize a documentação quando o comportamento do aplicativo mudar.
