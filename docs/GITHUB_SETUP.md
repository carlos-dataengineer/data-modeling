# Como apresentar o projeto no GitHub

**Nome do repositório:** `data-modeling`

**Descrição curta sugerida:**

> Ferramenta visual para desenhar, organizar e documentar modelos de dados, com tabelas, colunas, chaves, relacionamentos e exportação para SQL DDL, PySpark, Mermaid e JSON.

**Tópicos sugeridos:** `data-modeling`, `data-engineering`, `data-architecture`, `databricks`, `pyspark`, `schema-design`, `mermaid`, `agent-skill`.

Antes de publicar uma atualização:
- confira se os exemplos usam somente dados fictícios;
- revise os arquivos JSON e as capturas de tela;
- não inclua credenciais, tokens ou informações internas;
- execute os testes do projeto;
- atualize a documentação quando o comportamento do aplicativo mudar.
