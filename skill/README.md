# Skill Data Modeling

Esta Skill ajuda um agente de IA a instalar, explicar e orientar o uso do Data Modeling.

A ferramenta é um quadro visual para desenhar tabelas, colunas, chaves, relacionamentos e camadas de dados. A Skill contém instruções de uso, um guia de modelagem, o aplicativo e um instalador.

Consulte [`data-modeling/SKILL.md`](data-modeling/SKILL.md) para ver as instruções completas.
