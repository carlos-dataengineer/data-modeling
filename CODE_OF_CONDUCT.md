# Código de Conduta

Esperamos uma comunidade acolhedora, respeitosa e construtiva. Seja gentil, aceite críticas com maturidade, foque no que é melhor para o projeto e respeite diferentes níveis de experiência.

Comportamentos abusivos, assédio, discriminação, ataques pessoais e publicação de informações privadas não são aceitos. Mantenedores podem editar ou remover contribuições que violem estas regras e restringir participação quando necessário.

Para reportar uma situação, use o canal privado indicado em `SECURITY.md` ou entre em contato com os mantenedores pelo GitHub.
