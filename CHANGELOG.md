# Histórico de versões

## 1.0.5
- Reescrita da apresentação e da documentação para usar uma linguagem mais natural, direta e fácil de acompanhar.
- Incluídas representações visuais do quadro, do fluxo de trabalho e da escolha de exportação.
- Ampliadas as orientações práticas para definir grão, criar tabelas, marcar chaves, relacionar e organizar o modelo.
- Alinhadas a documentação principal e a Skill aos recursos reais da aplicação.


## 1.0.3
- Reescrita da apresentação do projeto em linguagem mais simples e direta.
- Adicionados diagramas de fluxo e representações conceituais de uso.
- Criado um guia prático com recomendações para modelar, revisar e exportar.
- Atualizada a Skill para explicar a ferramenta de forma acessível e fiel aos recursos atuais.

## 1.0.2
- Renomeado o projeto para Data Modeling.
- Padronizado o identificador da skill como `data-modeling`.
- Atualizados os títulos, caminhos de instalação, documentação e pacotes.

## 1.0.1 — correção da aplicação-fonte
- Adotada como base a aplicação HTML original enviada pelo usuário, preservando seu comportamento.
- Preservadas as capacidades existentes da aplicação original.
- Ajustada a identidade visual para Data Modeling e removido o catálogo `martech_dev` dos defaults.
- Reescrita a documentação para distinguir funcionalidades existentes de itens futuros.
- Atualizados exemplos para o formato JSON interno `schema-board`, mantido por compatibilidade, e dados fictícios.

## 1.0.0
- Primeira estrutura de empacotamento Data Modeling.
