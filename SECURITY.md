# Segurança

## Reportar vulnerabilidades
Não publique detalhes exploráveis em issues públicas. Abra um contato privado com o mantenedor por meio do recurso **Private vulnerability reporting** do GitHub, quando habilitado, ou solicite um canal privado no perfil do mantenedor.

Inclua versão afetada, impacto, passos mínimos para reproduzir e uma possível mitigação. Não inclua dados pessoais ou segredos reais.

## Dados e segredos
Nunca envie credenciais, tokens, dados pessoais ou dados corporativos reais para o repositório. Os exemplos devem ser sintéticos. A aplicação atual não envia dados para servidores; o estado é local ao navegador.
